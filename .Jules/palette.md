## 2025-05-15 - Discoverability of Keyboard Shortcuts

**Learning:** When adding keyboard shortcuts to a complex game interface, mere implementation is not enough for good UX. Users need visual cues (hints) co-located with the primary UI elements they control to discover and learn the shortcuts without referencing external documentation.

**Action:** Always pair keyboard shortcut implementation with small, non-intrusive UI labels (e.g., `[Space]`) on the associated buttons or interactive elements. This reduces cognitive load and improves accessibility for power users.
