## 2024-11-08 - Accessible Property Liquidations\n**Learning:** In ActionPanel, dynamically rendered `<button>` elements used for inspecting/liquidating properties lacked proper keyboard focus styles, which hurt accessibility for screen readers and keyboard users.\n**Action:** Add `focus-visible` utility classes (`focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-russia-gold`) to dynamic buttons used for selection.
