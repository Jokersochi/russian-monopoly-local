## 2026-08-20 - Player Panel Accordion Accessibility
**Learning:** The player details cards in the side panel act as accordions but were implemented with just `onClick` on a `div`. This is an inaccessible pattern. Furthermore, when adding custom interactive wrappers, adding `aria-label` is detrimental if the button contains rich text (like the player's name, money, and stats), as it overrides the child text content for screen reader users.
**Action:** When implementing custom `div`-based accordion headers, use `role="button"`, `tabIndex={0}`, `aria-expanded`, `aria-controls` matching the target's `id`, focus-visible styles, and an `onKeyDown` handler for 'Enter' and 'Space' that calls `e.preventDefault()` for Space to prevent page scrolling. Do not use `aria-label` when the wrapper contains informational child elements.
