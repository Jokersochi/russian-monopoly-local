## 2026-04-19 - Keyboard Accessibility for Div-based Accordions
**Learning:** In the `PlayerPanel.tsx` component, the custom accordion to expand player details was built using a generic `div` with an `onClick` handler. This pattern is inaccessible to keyboard users because `div` elements do not receive focus or respond to keyboard events by default, nor do they communicate their state to screen readers.
**Action:** When building or updating custom `div`-based accordion headers, always ensure they are semantically accessible by adding `role="button"`, `tabIndex={0}`, `aria-expanded`, and `aria-controls`. Focus-visible styles must be added for clear keyboard navigation feedback. Furthermore, an `onKeyDown` handler must be implemented to capture 'Enter' and 'Space' keys, ensuring `e.preventDefault()` is called for 'Space' to prevent standard page scrolling behavior.
