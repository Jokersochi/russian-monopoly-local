## 2026-08-20 - Accessible Icon-Only Filter Buttons
**Learning:** Using native `title` attributes for icon/emoji-heavy filter buttons (like in GameLog) creates a poor UX and lacks polish. Additionally, without proper ARIA attributes, screen readers cannot properly announce their function or state (which filter is active).
**Action:** When implementing icon-only filter or toggle buttons, replace native `title` attributes with Shadcn `Tooltip` components for UI polish, and always apply `aria-label` (using the tooltip text) and `aria-pressed` (using the active state) to the button element to ensure proper screen reader announcement and state indication. Apply `focus-visible:ring-2 focus-visible:ring-offset-1` with appropriate theme colors to ensure keyboard navigation visibility.
